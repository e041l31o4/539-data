# 539 DATA｜今彩 539 數據分析

今彩 539 歷史開獎資料、統計分析、模型組合與回測展示。模型只描述歷史資料，不代表能預測或提高未來中獎機率。

## 本機執行

需要 Node.js 20+。執行 `npm install`，再以 `npm run dev` 啟動網站。

## 資料更新

GitHub Actions 每日台灣時間 22:15 嘗試更新最近兩個月資料，也可手動執行完整歷史匯入。資料來源以台灣彩券官方公布為準。

## 機率提醒

今彩 539 從 1–39 選 5，所有組合機率相同；單注全中機率為 1 / 575,757。歷史頻率、遺漏值、尾數與回測不能改變下一期的隨機機率。

## 第一次啟用（必要）

1. 到 Repository 的 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選擇 **GitHub Actions**。
3. 到 **Actions → Update 539 history and deploy → Run workflow**。
4. 第一次請勾選 `full`，嘗試匯入官方 API 可提供的歷史資料（若需補齊更早年度，再接官方年度檔案）；完成後會自動部署網站。
5. 後續每天台灣時間 22:15 自動更新近兩個月資料並重新部署。

網站部署成功後，可在 **Settings → Pages** 查看 GitHub Pages 網址。

## 注意

- 初次完整匯入需要逐月向官方資料端點請求，可能耗時較久；若官方端點變更或暫時無回應，工作流程會失敗並保留原資料。
- GitHub Actions 的排程可能延遲，開獎資料以台灣彩券正式公告為準。
- 本專案的統計及回測屬歷史描述，不構成投注建議。
